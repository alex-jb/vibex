## Architecture Decisions / 架构决策

1. **@supabase/ssr** for server auth (official Next.js App Router approach)
2. **RPC functions** over triggers (explicit > clever)
3. **Mock adapter pattern** to collapse USE_SUPABASE branches
4. **Buffered realtime** for new-posts toast (prevents duplicate prepend)
5. **Foundation First** strategy (fix bugs before expanding, per outside voice review)
6. **Data moat** as real defensibility (not UI, not prompts)
