## 通用原则(每条都适用)

1. **不要 tag 大 V 在主帖** — 算法压流量。tag 在第一条 reply
2. **标题用具体数字**(5 users / 6 months / 3 products),不用形容词
3. **leading with vulnerability**(承认 fail),不要 leading with hype
4. **Ask + 留 link** 在底部,不要放最上面
5. **30 分钟内回每条评论** — 算法奖励 + 人感受到诚意
6. **不要在多平台同时发同一条** — 每平台微调措辞

---

## 文案 patterns 通用

每条都包含:

| 元素 | 例子 |
|---|---|
| **Hook**(开头 1-2 句) | "6 months solo, 5 users" |
| **Vulnerability** | "Hit the wall every indie hits" |
| **What you built** | "VibeXForge / Orallexa / SFOS" |
| **What you learned** | "Distribution is the bottleneck" |
| **Ask** | "Roasts / buddies / distribution tips" |
| **Link** | vibexforge.com |
| **Sign-off** | "I'll respond to every comment" |
