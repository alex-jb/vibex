# Code of Conduct

VibeXForge follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## TL;DR

- Be kind. Be patient. Critique code, not people.
- No harassment, sexualized language/imagery, or personal attacks.
- No trolling, dogpiling, or bad-faith engagement.
- Assume good intent. Ask before assuming malice.
- Use inclusive language, regardless of native tongue (EN / ZH / JP all welcome).

## Scope

This applies to all community spaces: GitHub issues/PRs/discussions, Discord (when we have one), Twitter replies tagging the repo, and any conference or meetup where VibeXForge is presented.

## Enforcement

Report violations privately to **xji1@mail.yu.edu** (will move to `abuse@vibexforge.com` once the domain email is configured). Maintainer will respond within 72 hours.

Consequences escalate per the Contributor Covenant:
1. **Correction** — private written warning + optional public apology request.
2. **Warning** — temporary ban from the community space.
3. **Temporary ban** — no interaction (even privately) for a defined period.
4. **Permanent ban** — no pattern of sustained inappropriate behavior tolerated.
